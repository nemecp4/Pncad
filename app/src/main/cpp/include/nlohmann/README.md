# nlohmann/json

This directory should contain the nlohmann/json single-header library (`json.hpp`).

## How to obtain

Download `json.hpp` from the latest release:

https://github.com/nlohmann/json/releases/latest

From the release assets, download the file named `json.hpp` (typically ~800KB)
and place it in this directory, replacing the placeholder file.

Direct download link (for a specific version, e.g. v3.11.3):
https://github.com/nlohmann/json/releases/download/v3.11.3/json.hpp

## Current state

The `json.hpp` file in this directory is a **minimal placeholder stub** that provides
just enough of the nlohmann::json interface for the project to compile. It does NOT
implement full JSON parsing functionality. Replace it with the real library before
running any actual JSON operations.
